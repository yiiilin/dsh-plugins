# @yiln-dsh/dsh-session-mode

Standalone DeepSeek Harness plugin. Installs on its own; it declares one
`dsh.bundle` layer and mounts a single Loader row.

    dsh plugin --profile <name> add "github:<owner>/<repo>#path:/pkgs/session-mode"

See [the module notes](../../docs/modules/session-mode.md) for behaviour, configuration
and verification.
