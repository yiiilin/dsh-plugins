# @yiln-dsh/dsh-desktop-vnc

Standalone DeepSeek Harness plugin. Installs on its own; it declares one
`dsh.bundle` layer and mounts a single Loader row.

    dsh plugin --profile <name> add "github:<owner>/<repo>#path:/pkgs/desktop-vnc"

See [the module notes](../../docs/modules/desktop-vnc.md) for behaviour, configuration
and verification.
