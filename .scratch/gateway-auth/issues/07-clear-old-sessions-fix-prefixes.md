# 07: 收尾——旧会话失效与前缀修复

**What to build:** 两件收尾的事，各自独立可验证。

**旧会话一次性失效**：换凭据模型后，之前用通行密钥建立的会话不该继续有效——那等于
旧凭据还在生效。清空既有会话，浏览器需要重新配对一次。

**前缀修复**：`gateway` 的管理界面还有六处用根绝对路径拼请求。在带前缀的部署下
（主环境是 `/main/`，联邦环境是 `/env-<id>/`），这种路径会逃出前缀，请求落到没有
前缀的路由上，被重定向到登录页——面板显示为空白，而且控制台没有报错，因为一个
HTML 登录页解析成 JSON 只会失败，不会留痕。

前缀解析**无法跨包共享**：每个插件包独立安装，client 半部必须自包含。所以这次只修
`gateway` 这一处真实缺陷，其余包各自实现但保持同一种写法——写法统一靠约定。

**Blocked by:** 06: 登录页只问一个配对凭据
