# 05: 配对凭据可用

**What to build:** 一个凭据能把浏览器与这台机器配对，换成一个会话。

这是**配对凭据**：一个密码，只用于用户验证。它与联邦的接入凭据是两回事——接入凭据
给机器看，配对凭据给人看，两者互不通用。它只做配对这一件事，换来会话之后不再重复出示，
也不能拿去当任何接口的调用凭证。

凭据本体不落盘：存的是 scrypt 哈希加盐，放在认证目录下的 `pairing.json` 里，权限 0600。
scrypt 用 Node 内置的，不新增依赖。

**名字不能撞**：`credentials.json` 已被 SSH 密码占用，`$DSH_HOME/.credentials.yaml`
已被模型 API key 占用。配对凭据另起名字，不复用。

**怎么进文件**：首次启动时若配了密码（配置项或环境变量），用 scrypt 哈希写入一次；
之后只读文件，环境变量不再当实时兜底——否则明文会一直留在 `.env` 里，与「凭据本体不落盘」
相抵。文件**损坏**时启动就失败。

**Blocked by:** 01: 让认证模块能接受一个可控的时钟
