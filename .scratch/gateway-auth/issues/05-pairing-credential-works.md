# 05: 配对凭据可用

**What to build:** 一个凭据能把浏览器与这台机器配对，换成一个会话。

这是**配对凭据**：一个密码，只用于用户验证。它与联邦的接入凭据是两回事——接入凭据
给机器看，配对凭据给人看，两者互不通用。它只做配对这一件事，换来会话之后不再重复出示，
也不能拿去当任何接口的调用凭证。

凭据本体不落盘：存的是 scrypt 哈希加盐，放在 DSH home 目录下的凭据文件里，权限 0600。
scrypt 用 Node 内置的，不新增依赖。

**Blocked by:** 01: 让认证模块能接受一个可控的时钟

**Status:** ready-for-agent

- [ ] 配对凭据能写入凭据文件，存的是 scrypt 哈希加盐，不是明文
- [ ] 凭据文件权限是 0600，目录权限是 0700
- [ ] 用正确的配对凭据能换到一个会话，用错误的不能
- [ ] 凭据文件缺失或损坏时，启动就报错，而不是等到第一个请求
- [ ] 哈希比对是常数时间的，不因凭据错误与否而泄露时间差
- [ ] 配对凭据与联邦的接入凭据互不通用：接入凭据不能配对，配对凭据不能接入联邦
