# 01: 让认证模块能接受一个可控的时钟

**What to build:** 认证模块接受一个时钟函数并把它传给它内部创建的会话存储，
这样「会话在什么时候过期」这件事在测试里可以被确定性地驱动，而不必真的等待。

存储本身已经接受时钟了，缺的是这一层转发——时钟传不进去，存储的过期与续期行为
就只能靠真的等待来观察，测试写不出来。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 认证模块接受一个时钟参数，缺省时用系统时间
- [ ] 该时钟被传给会话存储
- [ ] 现有行为不变：不传时钟时与改动前完全一致
- [ ] 有一个测试证明：传入一个可控时钟后，会话存储用的是它而不是系统时间
