# 06: 登录页只问一个配对凭据

**What to build:** 登录页从「用户名 + 密码 + 一次性码 + 通行密钥按钮」变成「只输一个
配对凭据」。使用者不需要再维护用户名、TOTP 密钥与通行密钥三样东西。

通行密钥与双因素整条路径同时消失：passkey 存储、WebAuthn 依赖、双因素配置项、
登录页的通行密钥按钮，全部移除。预置的通行密钥文件也不再被读取。

**顺序有硬约束**：这张票不能早于 05。配对凭据先可用，通行密钥才走得掉——反过来做
会把自己锁在外面（当前这台机器正是靠预置的通行密钥登录的）。

**Blocked by:** 03: 认证模块的接口只留真正被用到的东西、05: 配对凭据可用
**Status:** ready-for-agent

- [ ] 登录页只有一个输入框：配对凭据
- [ ] 用户名、一次性码、通行密钥按钮从页面上消失
- [ ] 配对凭据错误时给出清楚的中英文提示
- [ ] 通行密钥与双因素的实现、存储、配置项全部移除
- [ ] WebAuthn 依赖从包的依赖里移除
- [ ] 配对凭据正确时能登录并拿到会话
- [ ] 页面在无凭据、错误凭据、正确凭据三种情况下都有测试覆盖
