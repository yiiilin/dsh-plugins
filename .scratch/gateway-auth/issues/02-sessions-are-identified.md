# 02: 会话能被正确识别

**What to build:** 一个会话从建立到被认出、过期、被注销、并在重启后仍在，整条路径
都有测试保护。行为上看不见任何变化——变的是这些行为第一次被测住。

覆盖两层：存储层（创建、过期、空闲超时、cookie 续期、注销、持久化后重新加载）与
认证层（带有效 cookie 的请求被接受，带无效 cookie 的被拒绝，cookie 格式不对的被拒绝）。

测试断言行为，不断言源码写法。时钟用可控的假时钟，存储用临时目录，不碰生产路径。

**Blocked by:** 01: 让认证模块能接受一个可控的时钟

**Status:** ready-for-agent

- [ ] 会话存储的行为有测试：创建、绝对过期、空闲超时、cookie 续期、注销
- [ ] 会话存储在重启后仍能读回（持久化与重新加载）
- [ ] 认证层有测试：有效 cookie 被接受，无效 cookie 被拒绝，格式不对的 cookie 被拒绝
- [ ] 测试用假时钟与临时目录，不写生产路径、不真的等待
- [ ] 断言外部可观察的行为，不断言源码的字面写法
- [ ] 凭据文件缺失或损坏时，启动就报错，而不是等到第一个请求
