# 03: 认证模块的接口只留真正被用到的东西

**What to build:** 认证模块对外只暴露调用方真正使用的那几个成员，其余收进模块内部。

今天接口暴露出七个成员，其中四个从未在模块外部被调用过一次——它们是实现细节泄漏
到了接口上。调用方读代码时以为可以伸手进去改会话存储，实际上从没有人这么做过。

接口收窄后，模块内部的状态直接用内部引用，不再绕道返回值传出去。行为完全不变。

**Blocked by:** 02: 会话能被正确识别

**Status:** ready-for-agent

- [ ] 认证模块的公开接口只保留处理认证端点与查询当前会话的方法、渲染登录页的方法
- [ ] 会话存储实例、passkey 存储实例、双因素开关、realm 字符串不再出现在公开接口上
- [ ] 模块内部需要这些状态的地方直接用内部引用
- [ ] 行为完全不变：02 的测试全部继续通过
- [ ] 调用方代码不需要改动（本来就没用过被收窄的那几个）
