# 05: 列表行信息与并发提示

**What to build:** 列表每一行显示足够判断「这是不是我想要的」和「能不能关」的信息：
id（截短）、状态点、尺寸、创建者会话、最后活动时间、当前观看人数。两个客户端同时看一个
实例时，行上能看出不是自己一个人。

不显示「谁正在看」——那是别人的界面状态，既不可知也无用。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 每行显示 id（截短）、状态点、尺寸、创建者会话、最后活动时间、观看人数
- [ ] 状态为「启动中」的行不可聚焦，并明确标注，不显示为可用
- [ ] 状态为「失败」的行显示失败原因
- [ ] 观看人数来自服务端统计，两个客户端同时观看时数值正确
- [ ] 不显示「谁正在看」
- [ ] 新增测试：各状态的行渲染、观看人数反映真实连接数
