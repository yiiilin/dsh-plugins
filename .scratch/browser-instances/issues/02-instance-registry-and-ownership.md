# 02: 实例表与会话归属回收

**What to build:** Host 侧能维护一张浏览器实例表，并通过 HTTP 创建、列出、关闭实例。
每个实例记录它是哪个会话创建的；那个会话消失时，它名下的实例自动关闭，别的会话的实例
不受影响。

创建接口**立即返回**（`state: "starting"`），不等浏览器真正起来。列表接口返回扁平数组，
不带焦点、不带总数上限。
