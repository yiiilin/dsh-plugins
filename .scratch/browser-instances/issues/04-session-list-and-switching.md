# 04: 会话列表与查看器切换

**What to build:** 侧边栏的 VNC 页从一个纯查看器变成「左侧列表 + 右侧画面」。列表来自服务端的
实例表，所有客户端看到同一份；点击某一行就把右侧切到那个实例。没有选中任何实例时显示空态。

焦点是每个客户端各自的状态：两个客户端可以同时聚焦不同实例，各看各的。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] VNC 页内左侧渲染实例列表，数据来自服务端实例表
- [ ] 点击某一行，右侧画面切换到该实例
- [ ] 切换实例时旧的连接被正确释放，不留悬挂的 WebSocket
- [ ] 未选中任何实例时显示空态，不显示空画布
- [ ] 聚焦的实例被关闭时，右侧回到未选中状态，不自动跳到别的实例
- [ ] 焦点是客户端本地状态，不写入服务端、不跨客户端同步
- [ ] 现有查看器的连接状态机、重试上限、密码输入等行为在切换后仍然正确
- [ ] 新增测试：列表渲染、点击切换、切换时旧连接被释放
