# 03: 在界面上更换配对凭据

**What to build:** 已登录的人可以在一个管理端点上更换配对凭据：填当前凭据、新凭据、
确认。换完立刻生效，其他会话全部失效，自己这个保留。

今天换凭据只有两条路：编辑配置文件，或者登录机器删掉凭据文件再重启。前者要求能 SSH，
后者会让所有人登不进来。一个「怀疑凭据泄露」的运维，手上没有一条安全的换法。

**必须校验当前凭据**，不能只凭会话。会话默认寿命很长，只凭会话就允许更换登录凭据，
等于一次登录即可永久接管。

**必须立刻生效**，不能等重启。更换凭据的动机通常就是怀疑泄露，等重启生效会留下一个
窗口，而那正是这件事最不该有的。

撤销会话时**保留发起者自己**：它刚刚证明了同时知道新旧两个凭据，踢掉它只多一次无意义的
登录。其余会话一律失效——安全性不打折。

**Blocked by:** 02: 凭据文件不存在时引导设置

**Status:** done

- [x] 更换凭据需要一个已登录的会话
- [x] 必须提供正确的当前凭据；错误的被拒绝且不改动文件
- [x] 新凭据长度不足或两次输入不一致时被拒绝，且不改动文件
- [x] 成功后立刻生效：新凭据可用于登录，旧凭据不再可用
- [x] 成功后其他会话失效，发起者自己的会话仍然有效
- [x] 界面上不显示凭据的任何信息（无最后修改时间、无掩码、无提示片段）
- [x] 凭据文件权限保持 0600
