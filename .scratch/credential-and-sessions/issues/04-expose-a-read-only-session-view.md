# 04: 认证层暴露只读的会话视图

**What to build:** 认证层能回答「现在有哪些会话」，返回的字段刚好是展示需要的那些：
标识、客户端地址、客户端类型、签发时间、最后活动时间、过期时间、是否当前会话。

会话记录里这些都存着，存储层也已有脱敏后的投影，所以这是把既有能力接出来，不是新建模型。

上一轮把认证接口收窄到三个成员时，把会话列表排除在外——因为当时没有调用者。现在有了。
这不是回退：「谁登录着」本来就是认证层的职责。

本轮只读。撤销单个会话需要跨节点的写操作与失败回滚，不在本轮。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 认证层能返回当前所有会话
- [ ] 每个会话包含：标识、客户端地址、客户端类型、签发时间、最后活动时间、过期时间
- [ ] 能标出哪一个是发起查询的会话自己
- [ ] 返回值不含存储层的内部字段（如认证纪元）
- [ ] 过期会话不出现在结果里
- [ ] 这个能力是只读的，拿不到任何修改会话的途径
