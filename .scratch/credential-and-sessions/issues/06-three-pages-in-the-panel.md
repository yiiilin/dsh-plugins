# 06: 面板扩成三页

**What to build:** 联邦网关面板从单页面变成三个分页：**环境、凭据、会话**，默认停在环境。

- **环境**页保持今天的样子。
- **凭据**页是更换凭据的表单：当前凭据、新凭据、确认。界面上不显示凭据的任何信息。
- **会话**页是跨节点的会话表：客户端地址、客户端类型、最后活动时间、签发与过期时间、
  标识、来自哪个节点。离线、超时、报错的节点在该表里如实标注。

分页状态只在这个面板会话内保存，不跨会话、不进 URL。

所有新增文案走既有双语字典，中英各一份。

**Blocked by:** 03: 在界面上更换配对凭据、05: 跨节点的会话总览

**Status:** ready-for-agent

- [ ] 面板有三个分页：环境、凭据、会话
- [ ] 默认停在环境页，且它的行为与今天一致
- [ ] 凭据页能提交更换，成功与失败都有清楚反馈
- [ ] 凭据页不显示凭据的任何信息
- [ ] 会话页展示跨节点会话，字段齐全
- [ ] 会话页能区分离线、超时、报错的节点
- [ ] 会话页是只读的，没有撤销入口
- [ ] 分页状态不跨会话保存、不进 URL
- [ ] 所有新增文案中英各一份，键集合对齐
