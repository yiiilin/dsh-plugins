# 02: 凭据文件不存在时引导设置

**What to build:** 凭据文件不存在时，登录页不再是登录表单，而是设置凭据的引导：
输一遍新凭据、再输一遍确认，提交后直接进入已登录状态。

今天的行为是**启动失败**——宁可起不来，也不让人设置。那对一台刚装好的机器是死路：
没有凭据，进程不起来；进程不起来，就没地方设凭据。

判定条件只有一个：凭据文件不存在。不引入额外标记，不区分「首次安装」与「凭据被删」——
两者对使用者是同一件事。

**这里有一个明确接受的取舍**：不限制来源地址。凭据文件不存在期间，任何能访问守护进程
的人都可以设置凭据。它换来的是内网任意机器都能完成装机；代价是文件被删后的窗口期等于
敞开。这一点要写进代码注释与模块文档——通常的做法是收紧而不是放开，所以它是一个需要
被解释的默认值，不能只存在于设计记录里。

**Blocked by:** 01: 凭据只来自文件，不再由配置播种
