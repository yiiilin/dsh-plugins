# 版本记录

## 0.2.2 — 2026-09-18

修复“声明项目采用，但 agent 只跑 init，留下 enabled=true 而没有项目 skill/规则入口”的启用断链。

- 安装是所有项目采用模式的前置条件，不再只在用户另说“安装”时触发；完整接入与临时使用明确区分。
- `install.mjs` 成为唯一推荐的启用入口；配置/索引准备内聚为私有步骤，删除公开 `planInit`。旧 `init.mjs` 兼容转发完整安装 CLI，默认预览，显式 `--apply` 后安装全套产物；这是有意的行为变更。
- `enabled` 只表示意愿；doctor 输出派生的 `activation` 与 `requestedEnabled`，缺包/收据/入口等为 incomplete，提供安装下一步。版本不匹配也不能当作已装好本版。
- 预览明确 `setupComplete: false`，执行并静态核验 ready 才报告完成；新配置最后写入，保留回滚与锁检查。
- 直接修复旧 init-only 项目，无需删除/重写配置或 docs；兼容未改动 v0.2.0/v0.2.1 的安装迁移，保留区块保护、备份、个人改动拒绝覆盖。
- 更新 SKILL/README/INSTALL/ADOPTION 和缺配置错误信息，清除独立初始化推荐；增加半安装、兼容入口、禁用、失败回滚与文档保护回归测试。
- 修复多领域文档落点漂移：主入口、模板和接管示例统一为 domains/<domain>/features 与同领域 modules；领域概览只作可选导航，不替代契约，也不继续默认根部 features/modules。
- 增加 layout: domain/preserve 和只读目录检查。新接入默认领域布局；旧配置无字段按 preserve 读取且不改字节，首次接入已有受管功能/模块时亦保留旧布局。迁移先确认，不自动移动、复制或覆盖正文。
- doctor 单独报告布局状态，check-doc-set 对 domain 下受管当前规格路径错误报失败；不声称检查器能判断业务领域或检查全部未受管历史文档。

旧版本章节仅是历史记录，不是本版执行入口。

## 0.2.1 — 2026-09-18

补齐项目安装与生效检查，核心文档/确认/渐进及全量接管协议保持不变。

- 新增 `install.mjs`：默认只读预览，`--apply` 才部署；宿主入口适配、完整包哈希、安装收据及未修改 v0.2.0 的安全迁移。
- 新增 `doctor.mjs`：区分静态安装与真实 agent 加载；检测缺失、禁用、篡改/本地改动、入口过时与覆盖风险；`--probe` 输出新会话探测步骤，不声称替用户运行了模型。
- 新增 `uninstall.mjs`：默认预览，只删除未修改的受管区块和发行文件，保留源码、设计文档、配置、备份与额外个人文件。
- 规则和索引采用受管边界；保护边界外 UTF-8 原字节（包括 BOM、CRLF 和末尾换行情况）。遇到不完整标记、编码损失或局部改动停止，无 `--force`。
- 写前完成计划验证，保存旧文件备份，使用写前基线核对、安装锁、单文件临时替换及可捕获失败回滚；并发冲突不覆盖后来修改。强杀/断电恢复限制明确披露。
- 加强 `init`：所有索引检查先于写配置；保留原有项目规则，增加备份。安装元数据 `.doc-driven/` 不进入业务代码快照。
- 新增安装回归测试及 `INSTALL.md`，在 `SKILL.md` 明确禁止整篇重建其他项目规范或设计文档。没有新增强制 CI、钩子、宿主权限设置或审批平台。

## 0.2.0 — 2026-09-18

基于用户提供的 0.1.0 原始压缩包重构，不是对该项目代码做了逆向分析。

### 保留

保留先讨论再实现的确认关口、关键选择的推荐与代价、归属路径/接口名称、已有目录兼容、机械检查和原作者/第三方许可。

### 改变

- 从逐项转录转为遵守已确认需求和关键设计约束；允许明确边界内的实现自由。
- 功能文档按需求、概要、关键详细设计分层；共享模块独立，当前规格与本次提案区分。
- 将观察、获批、实现和验证区分；代码优先不自动批准所有新选择。
- 项目显式启用，不按目录形状误触发；不再将特定宿主的发现目录、描述截断等当作通用规则。
- 源码指针可选；普通 JSON、配置、测试和既有代码不必为了接管被批量插注释。
- 新增渐进接管、全量范围盘点、代码快照、按文件记录的阅读进度和可恢复批次。
- 提供安全初始化、盘点、生成索引、文档结构检查、变更范围门禁及自测；无第三方运行依赖。

### 清理

删除 skill 自己的四份长期设计/验证文档及重复生命周期说明，不再让使用者读一套“skill 的 skill 文档”；以单份使用说明、参考和场景替代。

删除强制词汇表及 `_Avoid_` 同义词约束、单独决策点格式、每个前提必须单独验证文件、按包一刀切、所有复杂函数伪代码化、索引状态手工复制、强制源文件反向指针、对其他 skill 的隐含依赖。

原始发行包中的试点估计和历史验证结论不移植为本版已验证效果。新增脚本测试检查可执行行为，不代表完成了跨模型长期真实项目试点。

### 旧项目迁移

不自动覆盖旧文档或批量修改代码。（0.2.0 当时的流程）先运行初始化并映射目录，再逐篇接管文档。0.2.2 已替换为 [完整安装与半安装修复](INSTALL.md)，不要再单独初始化。

旧 `draft` / `awaiting confirmation` 对目标文档映射为 `proposed`；逆向现状应为 `observed`。旧 `confirmed` 只有能找到真实确认记录才映射为 `accepted`。旧 `implemented` 必须拆查确认、实现和验证，不能无证据直接映成 `accepted + complete + passed`。旧 `superseded by ...` 分为 `Status: superseded` 与 `Superseded by`。

旧 `Version: vN` 改为 `Revision: N`；增加唯一 `Doc-ID`、`Type` 和 `Baseline`。`Owns` / `Owns names` 可以保留；已有源码 `doc:` 指针不必删除。未迁移文档不会被默认为新格式，但检查会提示发现的旧头部。
