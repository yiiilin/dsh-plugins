```sh
node scripts/check.mjs
# 只运行本版新增项：

```

新增覆盖实际运行与反例，而不仅是文案检查：

- 一次真实入口测试同时支持 integration/acceptance，无重复 E 和 unit.codeBaseline 仍通过文档与复杂交付核验；摘要只读，正文指针/状态更新不自我失效。
- 普通 runner passed 与严格交付都核对真实当前验收；无记录、假 hash、错误计划、无 profile、错误基线以及仅命令/静态检查均不能替代业务场景。
- 必测 SKIP/TODO、零执行、缺用例、断言失败、重复命名、纯文本 all passed、超时、输出超限、缺环境及人工待验收不能生成可冒充通过的引用。可选跳过有真实规则且明确披露，不能屏蔽失败。
- 规格正文/修订、代码、测试、配置、计划、规则、显式输入变化使记录过期；连未导入代码文件变化仍保守失效。本版没有缩窄快照来少跑测试。
- 日志变动、空输出、报告计数篡改、重新计算校验但与输出不符均拒绝。部分计划不能冒充整份规格覆盖，计划遗漏先于运行被拒绝。
- 完成单元缺运行/入口/层次/范围、无实施授权或给出矛盾旧字段不能通过；runner 规格不能在独立 delivery 中降级为旧手填模式。旧 E/--evidence 保持兼容，保留失败和矛盾检查。
- 真实运行不能代替用户批准、独立设计评审或人工验收。summary 错误参数零写入，计划不匹配/过期明确失败，不输出可以误用的成功指针。

所有批准来源和设计边界均为明确标注的测试夹具，不声称真实使用者批准。程序/测试确实执行，但测试仍不是业务语义完整性的证明。
