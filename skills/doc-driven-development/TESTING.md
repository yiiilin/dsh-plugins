## 安装保护覆盖

[tests/install.mjs](tests/install.mjs) 覆盖默认预览零写入、显式 apply、通用与宿主适配、Codex override 路由、Claude 已有入口、重复安装、升级归属、旧包识别、文件冲突、卸载与保留范围。

原文保护包含 UTF-8 BOM、中文、LF/CRLF/混合换行、无末尾换行、原空文件、区块前后个人改动、索引前后导航、原 JSON 字节和普通权限。验证非受管原文不被重新格式化。

反例包含改过的受管区块、缺失/反向/重复标记、围栏内标记、未闭合围栏/注释/头部、无效编码、UTF-16、大文件、只读文件、符号链接、硬链接、目录占位、越界路径、禁用配置、安装锁、旧包局部修改及额外个人文件冲突。

受控故障注入验证写前变化拒绝、修改前备份、部分写入后的回滚，以及不能用回滚覆盖之后发生的并发个人修改。它不模拟断电或所有文件系统竞态。

Doctor 测试验证只读、禁用配置不算通过、文件/区块丢失与过时检测、嵌套规则提示、大小预算风险、Git 忽略提示，以及将静态结果与实际 agent 会话严格分开。

[tests/run.mjs](tests/run.mjs) 保留原工作流、规格检查、确认/证据、代码快照与渐进/全量覆盖测试。部分审批与证据是明确标注的测试夹具，不是真实项目的批准记录。

## 使用上一版实际发行包的端到端试验

在独立临时项目中解开本会话提供的 v0.2.0 ZIP，放入 21 个原始发行文件，不用合成内容替代这次迁移来源。预置带 BOM/CRLF 的 AGENTS.md、已有 AGENTS.override.md/CLAUDE.md、自定义设计目录、非默认格式 JSON 配置、已有设计正文与源码。

执行“预览—正式升级—doctor—从已安装位置运行自检—无变化重装—追加个人规范—卸载”。检查预览零写入、升级前后原规则前缀和未管理正文逐字节相同、配置保持原字节、重装零修改、卸载恢复未改的原规则并保留后来添加的规则。设计正文与业务源码未修改。

这使用的是旧 skill 的真实发行内容，不是用户真实业务代码库。`doctor` 的 runtime 仍为 `not-run`。

## 重现

```sh
node scripts/check.mjs
node --test tests/run.mjs tests/install.mjs
```

第一条同时校验包 manifest、元数据、相对链接、全部脚本语法和两组隔离测试。ZIP/TGZ 发行归档在解包后执行同一自检，并逐文件比较 SHA-256 内容一致性；归档本身的校验值随包提供。

## 未验证与边界

未在 Windows/macOS、其他 Node.js 版本、真实 agent 宿主或多模型长期项目中实测。换行/路径测试不等于完成跨平台验证；静态通过不证明自动加载、后续遵守、真实批准、命令实际执行或业务正确性。

备份/锁/临时替换不是跨文件断电级事务；遇到强杀、断电或回滚冲突需按 [INSTALL.md](INSTALL.md) 核对日志和后续修改，不能盲目覆盖原文件。SHA-256 清单用于完整性核对，不是独立可信签名或防篡改审批系统。
